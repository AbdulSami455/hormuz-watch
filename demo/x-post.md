Just built Hormuz Watch 🛰️

A live map of reported ship strikes in the Strait of Hormuz, pulled from public maritime + world news feeds.

Mines, missiles, drones: pinned, filterable, searchable.

Open source 👇
https://github.com/AbdulSami455/hormuz-watch

## Optional reply (thread)

How it works:
• Pulls RSS from gCaptain, Maritime Executive, Splash247, BBC, Al Jazeera, Guardian + more
• Keeps only stories about vessels hit near Hormuz
• Places each one on the map and on a timeline
• Refreshes every 5 min

React + Leaflet + Vite. No API keys.
