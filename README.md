# Hormuz Watch

Live map of ship-hit reports around the Strait of Hormuz. News comes from public RSS feeds (gCaptain, Maritime Executive, Splash247, BBC, Al Jazeera, Guardian and more). The map uses Esri dark-gray tiles built on OpenStreetMap data.

https://github.com/AbdulSami455/hormuz-watch/raw/main/demo/hormuz-watch-demo.mp4

```sh
npm install
npm run dev
```

- Time ranges: 2 days, 7 days, 30 days, 60 days, 1 year, all.
- Filter by mine, missile, drone or attack; search across titles, sources and places.
- Timeline of reports; click a report and the map flies to it.
- `J` / `K` or arrow keys step through reports. Feeds refresh every 5 minutes.

Pins are placed by the place named in each story, so positions are approximate.
